# ShimejiAdjuster
I wanted a program that makes it easier to adjust the behavior of some desktop pets (Shimeji by Kilkakon).

The program is dropped into the base shimeji folder and accsses the behavior file to read and edit the frequency for certain actions.  The labels 
display the current values, and the sliders for the behaviors change in increments of 25, with a current max of 250.  Changes aren't saved until 
the save button is clicked.  The shimeji must be re-loaded for changes to take effect.
